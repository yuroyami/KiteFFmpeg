# kiteffmpeg-gpl

This directory is not a module. It is not built and not published, and `settings.gradle.kts` does
not include it.

KiteFFmpeg publishes one flavour, the LGPL build in `kiteffmpeg`. A GPL FFmpeg tree is one that you
build and own yourself. [Licensing](../docs/licensing.md) says how to point this repository's build
at such a tree.
