kite.mjs and kite.wasm, the KiteFFmpeg web codec module, contain compiled FFmpeg libraries
(LGPL-2.1-or-later). KiteFFmpeg's own code is Apache-2.0. The web build contains no dav1d and
no zlib.

FFmpeg source (the exact tag this build was compiled from, with KiteFFmpeg's patches applied;
the two together are the complete corresponding source):
  https://github.com/yuroyami/KiteFFmpeg/releases  (assets: ffmpeg-<version>-source.tar.gz
  and ffmpeg-<version>-patches.tar.gz)
  https://github.com/yuroyami/KiteFFmpeg/tree/main/native/patches/ffmpeg  (the patches)
  https://github.com/FFmpeg/FFmpeg

COPYING.LGPLv2.1 applies to the FFmpeg portions. Consumer obligations (notice, source offer,
LGPL section 6) are summarised in the repository NOTICE and README:
https://github.com/yuroyami/KiteFFmpeg

This software is based in part on the work of the Independent JPEG Group.
FFmpeg compiles three files of the IJG's libjpeg; FFMPEG-LICENSE.md beside this file asks
for that line in the documentation of anything that ships the binaries.
