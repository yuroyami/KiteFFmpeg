# Fonts

The feature graphic uses two fonts, both under the SIL Open Font License 1.1.
The files are the latin subsets that Google Fonts serves, so the page renders the same on every machine.

| File | Font | License |
| --- | --- | --- |
| `ibm-plex-sans-latin.woff2` | [IBM Plex Sans](https://github.com/IBM/plex), variable weight 100 to 700 | `OFL-IBMPlexSans.txt` |
| `ibm-plex-mono-400-latin.woff2`, `-500-`, `-600-` | [IBM Plex Mono](https://github.com/IBM/plex), weights 400, 500 and 600 | `OFL-IBMPlexMono.txt` |
