KiteFFmpeg

FFmpeg for Kotlin Multiplatform, as plain Kotlin calls.
No ffmpeg process. FFmpeg is inside the artifact.

$ ffmpeg -i movie.mkv -c copy movie.mp4
Remuxer.remux(input = "movie.mkv", output = "movie.mp4")

Convert·Cut·Filter·Read every frame·Grab one frame·Read bytes from your own code
