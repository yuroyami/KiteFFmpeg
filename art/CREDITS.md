# Artwork credits

## FFmpeg mark sources

`third-party/ffmpeg3d_white.png` is an unmodified copy of the white FFmpeg
mark published in the official FFmpeg website repository:

- Source: <https://github.com/FFmpeg/web/blob/master/htdocs/img/ffmpeg3d_white.png>
- Project: <https://ffmpeg.org/>
- Artwork credit: illustrator Hervé Flores, as recorded in FFmpeg's official
  development-list correspondence:
  <https://ffmpeg.org/pipermail/ffmpeg-devel/2011-May/112294.html>
- Retrieved: 2026-08-31
- SHA-256: `72945c128bf3659ba1b1c58da29290601bcdccba401856318df0b7003e9b02e2`

`third-party/ffmpeg-logo-new.svg` is a whitespace-normalized local copy of the
2011 logo vectorisation hosted by Wikimedia Commons:

- Source: <https://commons.wikimedia.org/wiki/File:FFmpeg_Logo_new.svg>
- Original artwork: Hervé Flores
- Vectorisation: Vulphere, optimized by VulcanSphere
- Commons classification: public-domain simple geometric/text logo, with a
  separate trademark warning
- Retrieved: 2026-09-01
- Local SHA-256: `5f8445672293c9d9e18c2a31f48dd6176ab1cc748cefe06de916d9f5b1e524a2`

The source PNG is stored byte-for-byte unchanged and remains embedded in the
final SVGs for provenance. To avoid enlarging a 102-pixel bitmap, the rendered
inlay uses only the graphic portion of the credited vectorisation; the FFmpeg
wordmark is omitted. The mark becomes a pale membrane window inside the same
wind-loaded outer kite used by KitePlayer. Sail seams terminate at that window,
so it is part of the construction rather than a separate badge.

That KiteFFmpeg composition is independently designed and is not official
FFmpeg artwork. It references KiteFFmpeg's FFmpeg dependency as part of
KiteFFmpeg's own library branding.

FFmpeg is a trademark of Fabrice Bellard, originator of the FFmpeg project.
KiteFFmpeg is an independent project and is not endorsed by, sponsored by, or

Wikimedia Commons classifies its vectorisation as public-domain simple geometry,
but also flags the logo as trademarked. Separately, the 2011 correspondence
grants broad rights to the **FFmpeg Project** for 99 years; it is not a clear
downstream branding license to KiteFFmpeg. Attribution does not itself resolve
trademark use. Obtain appropriate clearance before publishing this derivative

This repository therefore keeps the image clearly separated as third-party
material. Neither source mark nor the derivative KiteFFmpeg logo is covered by
